# 青空リーダー

青空文庫の作品を、縦書き・横書きで読めるリーダーです。ビルド工程のいらない静的サイトで、iPhone のホーム画面に追加してアプリのように使えます(PWA)。

## できること

- 作者・作品名で検索(五十音順、よみがなでも検索、あ行〜わ行の絞り込み)
- 栞、積読(あとで読む)、お気に入り、読了、本棚
- 縦書き / 横書き(ページ切替・縦スクロール1枚)、文字サイズ、ダーク表示
- 左右タップ・上下タップ・スワイプでのページ送り
- 1画面に表示する文の数の制限(「。」までを1文、「」のセリフは丸ごと1文)
- ルビ表示、見出しの強調、オフライン読書(いちど開いた作品は通信なしで読める)

## 仕組み

```
ブラウザ ── data/catalog.json ──── 作品一覧(題名・作者・よみ)。公開のたびに作り直す
   │
   └── 作品の本文 ── raw.githubusercontent.com/aozorahack/aozorabunko_text/…(青空文庫形式のテキスト)
```

- 作品一覧は、青空文庫の「公開中 作家別作品一覧拡張版」CSVから作ります(`scripts/build-catalog.mjs`)。著作権が切れた作品(作品・人物の著作権フラグがともに「なし」)だけを載せます。
- 本文は、ブラウザが `aozorahack/aozorabunko_text`(青空文庫のテキストを毎日集めた公開リポジトリ)から直接取得します。Shift_JIS のテキストを読み込み、ルビ(《》)・見出し・外字などの注記を、アプリ側で変換します。
- 取得した本文は端末に保存されるので、2回目からは通信しません。
- 取得先は `index.html` の `TEXT_BASES` にあります。別の配信元に変えるときは、ここを書き換えてください。

## ローカルで動かす

```
python3 -m http.server 8000     # または npm run dev
```

`http://localhost:8000` を開きます。`data/catalog.json` には、動作確認用の11作品だけが入っています。全作品の一覧にするには、下の「公開する」の手順でビルドします。

## 公開する(GitHub Pages)

1. GitHub で新しいリポジトリを作り、このフォルダの中身を `main` ブランチに push します。
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にします。
3. Actions タブの「Deploy」を実行します(push でも動きます)。
4. 数分後に、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

`.github/workflows/deploy.yml` は、push のたびと、毎日 06:00(日本時間)に動き、最新の作品一覧で作り直して公開します。

### Cloudflare Pages など、ほかの静的ホスティング

- ビルドコマンド: `bash scripts/build-site.sh`
- 出力ディレクトリ: `dist`
- Node.js 22 以上、git が使える環境が必要です。毎日の更新は、サービス側の Deploy Hook を定期実行して行います。

## iPhone でアプリのように使う

公開した URL を Safari で開き、共有ボタン →「ホーム画面に追加」を選びます。

## 更新・保守

- 作品一覧の更新は、毎日の自動ビルドで反映されます。手動では `npm run build` で `dist/` を作れます。
- 公式CSVの列名が変わった場合、`build-catalog.mjs` が不足している列名を表示して止まります。
- 読書位置・栞・お気に入りは、端末のブラウザ内(localStorage)に保存されます。端末をまたいだ同期はありません。

## 注意

- 作品は、[青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)の範囲でご利用ください。
- `aozorahack/aozorabunko_text` は非公式のミラーで、可用性の保証はありません。大量のアクセスを想定する場合は、自前の配信元に本文を置くことを検討してください。
- 外字のうち、Unicode に直せないものは「〓」で表示します。傍点などの装飾の注記は、まだ表示に反映していません。
- 同じ作品に新字新仮名と旧字旧仮名の版がある場合は、別々の作品として2件並びます。
